# Multi-Tier Laying Hen House Build Plan

## Project Overview
A 4-post frame (4.5 ft wide × 5 ft long × 7.5 ft high) with 4 tiers for laying hens, featuring hardware cloth enclosure, manure management system, and integrated equipment.

**Capacity:** 40–50 birds  
**Frame Height:** 7.5 ft  
**Footprint:** 4.5 × 5 ft (22.5 sq ft)  
**Tier Height Spacing:** 10, 30, 50, and 70 inches

---

## Pre-Build Checklist

### Legal & Planning
- [ ] Check local zoning laws for poultry housing
- [ ] Verify setback distances from property lines
- [ ] Confirm building permit requirements
- [ ] Check HOA or municipality restrictions
- [ ] Inspect structural requirements (flood zones, wind load, snow load)
- [ ] Calculate floor load capacity (estimate ~5–10 lbs per bird + equipment)
- [ ] Locate underground utilities (gas, electric, water, septic)
- [ ] Plan drainage around structure

---

## Step 1: Frame Construction (4-Post Frame)

### Materials
- 4 posts: 4×4 galvanized square tubing or angle iron, ~8 ft long
- Horizontal rails: 2×4 galvanized square tubing or angle iron
- Bolts, brackets, welds (if using tubing)
- Level, tape measure, carpenter's square

### Assembly
- [ ] Set 4 posts in corners, 4.5 ft × 5 ft apart
- [ ] Ensure posts are plumb (use level)
- [ ] Add horizontal rails at:
  - 10 inches (Tier 1 floor)
  - 30 inches (Tier 2 floor)
  - 50 inches (Tier 3 floor)
  - 70 inches (Tier 4 floor)
- [ ] Bolt or weld rails securely to posts
- [ ] Add diagonal bracing for lateral support
- [ ] Verify frame is square and level

---

## Step 2: Floors & Manure Management

### Materials (per tier)
- Sloped galvanized sheet or plastic tray (7–10° slope)
- Stainless steel or galvanized manure tray (removable)
- 1/2 in PVC pipe or metal channels for slope support
- Fasteners (bolts, clips)

### Installation
- [ ] Install slope supports under each tier floor
- [ ] Slope floor 7–10° toward one end (for egg roll-away)
- [ ] Attach galvanized sheet or plastic tray to frame
- [ ] Install removable manure tray below each tier (with ~6 in clearance)
- [ ] Test tray removal & ease of cleaning
- [ ] Ensure gutters direct manure into trays

---

## Step 3: Hardware Cloth Enclosure

### Materials
- 1/2 in hardware cloth (50 ft roll, galvanized preferred)
- Staples or rivets for fastening
- Wooden frame trim (2×2 or 2×4) to edge posts
- Wire cutters, staple gun

### Coverage
- [ ] Cover all four sides with 1/2 in hardware cloth
- [ ] Cover back panel completely
- [ ] Plan front doors (see Step 6)
- [ ] Staple or rivet cloth to frame at 3–4 in intervals
- [ ] Fold edges back and double-staple for security
- [ ] Check for sharp points and file smooth
- [ ] Inspect for gaps (predator-proof)

---

## Step 4: Doors & Latches

### Materials (per tier)
- Frame: 2×2 or 2×4 galvanized square tubing
- Hardware cloth covering
- Heavy-duty hinges (3 per door)
- Strong latches or hooks (2–3 per door)
- Bolts, rivets, fasteners

### Construction
- [ ] Build full-width door frame for each tier (4 doors total)
- [ ] Cover each door with 1/2 in hardware cloth
- [ ] Mount on heavy-duty hinges at posts
- [ ] Install 2–3 strong latches per door (slide bolt, chain hook, or barrel bolt)
- [ ] Test door swing and latch engagement
- [ ] Ensure doors can't be forced open by predators
- [ ] Add door stops to prevent over-swing

---

## Step 5: Equipment Installation – Feeding & Watering

### Feed Trough
- [ ] Install V-shaped or trough feeder along front of each tier
- [ ] Allow 4–6 linear inches per bird
  - Example: 40 birds ÷ 4 tiers = 10 birds/tier → ~50 in trough per tier
- [ ] Mount 12–18 in above floor level
- [ ] Secure against tipping
- [ ] Use removable troughs for easy cleaning

### Nipple Drinker System
- [ ] Run 1/2 in PVC line along front or side of each tier
- [ ] Install 1 nipple per 3–4 birds
  - Example: 40 birds ÷ 4 tiers = 10 birds/tier → ~3 nipples per tier
- [ ] Mount at 6–8 in above bird head level (adjust as birds grow)
- [ ] Test for leaks; attach drip tray beneath
- [ ] Install shutoff valve for winterization
- [ ] Ensure water line is insulated if used year-round in cold climates

---

## Step 6: Perches & Nest Boxes

### Perches
- [ ] Install 1–1.5 in wooden dowel or PVC perch in each tier
- [ ] Allow 8 linear inches per hen
  - Example: 10 birds/tier → ~80 in (6.7 ft) of perch per tier
- [ ] Mount 12–18 in below roof/top of tier
- [ ] Angle slightly downward to rear (helps with manure drop)
- [ ] Space multiple perches 12 in apart if needed

### Nest Boxes
- [ ] Install 1 roll-away nest box per 4–5 hens
  - Example: 40 birds → 8–10 nest boxes
- [ ] Each box: ~12 × 12 × 12 in interior
- [ ] Mount on Tier 3 or 4 (elevated for roll-away eggs)
- [ ] Slope floor 2–3° toward egg exit
- [ ] Provide curtain or privacy slats
- [ ] Bedding: pine shavings, ~3 in deep
- [ ] Check egg collection weekly, change bedding 2×/week

---

## Step 7: Ventilation System

### Exhaust Fan
- [ ] Size: 300–500 CFM for 40–50 birds
  - Rule: ~8–10 CFM per bird minimum
- [ ] Mount near top of structure (high outlet)
- [ ] Install ductwork or direct outlet to outside
- [ ] Use thermostat or temperature controller (activate at 75°F+)
- [ ] Include damper for winter (prevent drafts)

### Fresh Air Inlets
- [ ] Install low inlets near floor level (opposite side from exhaust)
- [ ] Size: ~1 sq in inlet per bird (400–500 sq in for 40 birds)
- [ ] Use adjustable louvers to control intake
- [ ] Place inlets away from direct wind
- [ ] Screen inlets to prevent pest entry

### Ductwork & Sealing
- [ ] Seal all seams and joints with silicone or caulk
- [ ] Insulate ducts in cold climates to prevent condensation
- [ ] Test airflow after installation

---

## Step 8: Lighting System

### LED Lights
- [ ] Install 2–4 dimmable LED panels (or fixtures)
- [ ] Total: ~0.5–1 watt per sq ft (11–22 watts for 22.5 sq ft)
- [ ] Mount 6–8 ft above floor for even coverage
- [ ] Use warm white (2700K) or full-spectrum bulbs

### Timer & Control
- [ ] Install 24-hour programmable timer
- [ ] Schedule for layers: 14–16 hours light daily
  - Example: 5 AM on, 7 PM off (14 hours)
- [ ] Mount timer in weatherproof enclosure
- [ ] Use GFCI outlet for safety

### Wiring
- [ ] Use 12 or 14 AWG wire (appropriate to breaker size)
- [ ] Install waterproof conduit and fittings
- [ ] All connections GFCI-protected
- [ ] Breaker size: 15 A typical for low-power setup

---

## Step 9: Electrical & Temperature Control

### Power Distribution
- [ ] Run dedicated circuit from breaker panel (~20 A, 120V typical)
- [ ] Install main disconnect switch near entrance
- [ ] Use GFCI breaker or outlet for all circuits
- [ ] Outdoor-rated conduit and waterproof boxes

### Thermostat & Fan Control
- [ ] Install temperature sensor inside coop
- [ ] Connect to thermostat controller
- [ ] Set fan to activate at 75°F (24°C)
- [ ] Wire fan to thermostat through relay (if needed)
- [ ] Test operation in various conditions

### Backup Power (Optional)
- [ ] Consider battery backup for fan/lights during outage
- [ ] Essential if climate extremes are expected

---

## Step 10: Finishing & Sanitation

### Edge Treatment
- [ ] Inspect all cut edges (hardware cloth, tubing, sheet metal)
- [ ] File or grind sharp points smooth
- [ ] Wrap exposed edges with trim or tape if needed
- [ ] Seal any gaps where predators could squeeze

### Sealing & Weatherproofing
- [ ] Caulk or seal seams to prevent water infiltration
- [ ] Apply rust-preventative paint to bare metal (if not galvanized)
- [ ] Ensure roof/top has slight slope for drainage
- [ ] Install gutters if needed to divert water away

### Washability & Cleaning Access
- [ ] Design all surfaces for hosedown
- [ ] Removable trays for manure and feeders
- [ ] Sloped, hard floors (galvanized sheet, plastic)
- [ ] Plan drainage path to yard/compost
- [ ] Avoid corners and crevices where bacteria hide
- [ ] Install small access doors for deep cleaning

### Final Inspection
- [ ] Walk through each tier; sit/crouch to check predator entry points
- [ ] Open/close all doors multiple times
- [ ] Test nipple drinkers (no leaks)
- [ ] Verify lights and fan operation
- [ ] Check ventilation (airflow, no drafts)
- [ ] Confirm all latches hold firmly

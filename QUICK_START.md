# Quick Start Checklist

## Pre-Build (Week 1)
- [ ] Research local zoning & permitting
- [ ] Check floor load requirements
- [ ] Order materials (frame, hardware cloth, equipment)
- [ ] Gather tools (welder, staple gun, level, tape measure)
- [ ] Obtain building permit if required
- [ ] Locate utilities

## Build Phase (Weeks 2-4)

### Week 1: Frame
- [ ] Cut and prepare posts and rails
- [ ] Assemble 4-post frame
- [ ] Install horizontal rails at 10, 30, 50, 70 inches
- [ ] Add diagonal bracing
- [ ] Verify square and level

### Week 2: Floors & Enclosure
- [ ] Install sloped floor supports
- [ ] Attach galvanized trays to frame
- [ ] Install manure trays below each tier
- [ ] Cover sides and back with hardware cloth
- [ ] Secure with staples/rivets

### Week 3: Doors & Equipment
- [ ] Build 4 full-width doors
- [ ] Install hinges and latches
- [ ] Install feed troughs (4 tiers)
- [ ] Install nipple drinker system
- [ ] Mount perches

### Week 4: Finishing
- [ ] Install nest boxes
- [ ] Install ventilation fan & inlets
- [ ] Install LED lights & timer
- [ ] Run electrical & thermostat
- [ ] Final inspection & edge treatment

## Post-Build (Ongoing)

### Weekly
- [ ] Clean manure trays
- [ ] Inspect doors, latches, enclosure
- [ ] Test lights and fan

### Monthly
- [ ] Deep clean floors & trays
- [ ] Check electrical & thermostat
- [ ] Inspect for pest entry points

### Seasonal
- [ ] Fall: Winterize water line, check insulation
- [ ] Spring: Full inspection & repairs

---

## Tools Needed
- Level (4 ft)
- Tape measure (25 ft)
- Drill/driver
- Staple gun & staples
- Wire cutters
- Welder (if using tubing) or bolts/brackets
- Grinder (for sharp edges)
- Carpenter's square
- Ladder or scaffolding

## Safety
- Wear gloves when handling hardware cloth
- Use eye protection when grinding/welding
- Ensure electrical work is GFCI-protected
- Have fire extinguisher on hand if welding
